# OmniDex Project Page

Static project page for **OmniDex: Scaling Dexterous Hand Grasping to Diverse Cluttered Scenes**.

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static file server.

## GitHub Pages

Create a repository named `OmniDex`, push this directory to its default branch, then enable Pages from the repository's settings using the root of the branch as the deployment source.

The placeholder Code link in `index.html` should be replaced with the final code repository URL before publishing.

## Included assets

Only selected presentation assets are included. The original paper workspace and raw benchmark directories remain outside this project folder and are not modified by this site.
